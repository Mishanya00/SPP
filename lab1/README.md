# Рядом — серверный календарь встреч

Учебный проект для лабораторной работы №1: календарь с серверным рендерингом на Node.js, Express и EJS. На главной странице показываются ближайшие 3 дня, а переключатель меняет период на 7 дней.

## Возможности

- создание встречи на выбранную дату и время;
- продолжительность от 15 минут до 8 часов;
- режимы отображения «3 дня» и «7 дней»;
- редактирование и удаление встреч;
- корректное отображение пересекающихся встреч;
- валидация данных на сервере;
- сохранение данных в `data/meetings.json`;
- адаптивный интерфейс для компьютера и телефона.

Все основные страницы формируются на сервере. Данные отправляются обычными HTML-формами (`application/x-www-form-urlencoded`), JavaScript используется только для небольших улучшений интерфейса.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

После запуска откройте [http://localhost:3000](http://localhost:3000).

Для обычного запуска без автоматической перезагрузки:

```bash
npm start
```

## Структура

```text
src/app.js                 настройка Express и маршруты
src/server.js              запуск HTTP-сервера
src/meeting-repository.js  JSON-хранилище встреч
src/meeting-service.js     валидация и раскладка пересечений
views/                     EJS-шаблоны
public/                    стили и небольшой клиентский скрипт
data/meetings.json         сохранённые встречи
```
